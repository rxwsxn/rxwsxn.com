# rxwsxn.com

Personal site for **Raushan Kumar** (`ai + product`, Bangalore / remote).
Always-dark, Liquid Glass surfaces over a drifting colour field, with a
geometric / pixel backdrop. Astro static output, one hand-written stylesheet,
markdown content collections.

## Run it

Requires **Node 20+** (Astro 5).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
npm run preview  # serve the built site
```

## Where things live

```
src/
  site.config.ts        # name, tagline, hero, asides, links — edit me first
  styles/global.css     # the only stylesheet (tokens + geometry + glass layers)
  layouts/Base.astro    # <head>, meta, OG/Twitter, JSON-LD, header + footer
  components/
    Header.astro  Footer.astro  CopyEmail.astro  Hero.astro
  content/
    blog/*.md(x)          # dated notes -> /blog/<slug>
    work/*.md(x)          # work entries -> the /about "details" section
  pages/
    index.astro           # /  (hero + links to blog / about / contact)
    blog/index.astro      # /blog
    blog/[slug].astro     # /blog/<slug>
    about.astro           # bio + details (work) + asides
    contact.astro  404.astro  rss.xml.ts
scripts/
  generate-og.py          # social cards + app icon
public/                   # robots.txt, favicon.svg, og.png, og/, _headers, manifest
```

## Editing content

- **Blog posts** — add a file to `src/content/blog/`. Frontmatter:
  `title`, `date`, `summary`, `tags: []`, `draft`.
- **Work / details** — add a file to `src/content/work/`. Frontmatter:
  `title`, `summary`, `org`, `period`, `stack: []`, `links: [{ label, href }]`,
  `order`. These render in the **details** section of `/about`.
- **Name / hero / asides / links** — `src/site.config.ts`. `wordmark` is the
  display name used in the header, page titles and RSS.

## Social cards

Every page has its own 1200x630 card, generated by `scripts/generate-og.py`
(needs Pillow: `pip3 install pillow`):

- `public/og.png` — home / default fallback
- `public/og/blog.png`, `og/about.png`, `og/contact.png` — one per page
- `public/og/<slug>.png` — one per blog post

Each is a Liquid Glass panel carrying its own mathematical figure, with the
current page highlighted in the nav line. Regenerate after adding or editing
content:

```bash
npm run images    # or: python3 scripts/generate-og.py
```

`Base.astro` falls back to `/og.png` if a page's card is missing, so the meta
tags never point at a 404.

Commit the regenerated PNGs. SEO meta (Open Graph, Twitter, canonical, JSON-LD)
is emitted from `src/layouts/Base.astro`; identity defaults live in
`src/site.config.ts`.

## Visitor counter

The footer shows a live line — visitor number, a masked IP and the country —
served by a Cloudflare Pages Function at `functions/api/visit.js`. The count
lives in a KV namespace bound as `VISITS` (see DEPLOY.md). Without the binding
the number is omitted; in plain `astro dev` the function doesn't run, so the
whole line stays hidden rather than showing anything fake.

Privacy: the full IP never leaves the edge — the function reduces it to a
partial address, and it's only ever shown back to the visitor themselves.

## Deploy

See `DEPLOY.md`. `dist/` is static — Cloudflare Pages, Netlify, Vercel, or any
static host. `site` in `astro.config.mjs` drives the sitemap and canonical URLs.
